# Project Instructions

This project uses GitHub Spec Kit with Spec-Driven Development and Harness Engineering.

Before implementation:

- Read the active feature's spec.md, plan.md, tasks.md.
- Do not implement behavior outside the current spec and task.
- If acceptance criteria are unclear, stop and ask for clarification.
- Prefer small, reviewable changes.

During implementation:

- Map each code change to a task in tasks.md.
- Add or update tests before or alongside implementation.
- Use existing fixtures and golden cases when available.
- Do not use production-sensitive data in prompts, tests, fixtures or logs.

Before finishing:

- Run the relevant project checks.
- Report risks, assumptions and trade-offs.
